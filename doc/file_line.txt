CONFIGURATION                                          *file_line_configuration*

------------------------------------------------------------------------------
file_line.setup(opts)                                          *file_line.setup* 

The {setup} function takes a `table` or `nil`. The table can have the
following fields:

    {register}	(`boolean`):
		    Intercepts new files being edited with a name matching a
		    pattern above and interprets the line and column number.
		    (default: `true`)
    {on_open}	(`file_line.OnOpenFn?`):
		    A callback to be invoked before the file is opened by the
		    plugin. Not invoked when the file is opened without the
		    line, column pattern.
		    (default: `nil`)
    {enable_gf}	(`file_line.EnableGF?`)
		    This is added just for convenience, it maps `gf` to `gF`
		    in normal mode, so that `gf` opens files followed by line
		    numbers. Note that this is not quite the same pattern as
		    is enabled by this plugin, this is (neo)vim built-in
		    functionality.

		    If `enable_gf` is a table, it is expected to have one of
		    two keys (but not both!), `match_pat` or `ignore_pat`:
		    This will match the file name will or will not enable the
		    mapping for that file respectively.

		    If `enable_gf` is `true`, it is enabled on all files.
		    (default: `false`)

API                                                              *file_line_api*

------------------------------------------------------------------------------
file_line.openFileOnLine(name, line, col, winnr)      *file_line.openFileOnLine*

    Opens a file and jumps to the required line and column.

    If both {line} and {col} are `nil`, does not open the file and returns
    `false`. If {col} is `nil`, it is set to 0.

    {winnr} can be used to specify which window to open the file in. If it is
    a number, it is interpreted a window ID. If it is a string, it will be
    first passed to |winnr()|. If `nil`, current window is used.

    Parameters:
        {name}  (string): Path of the file to open.
        {line}  (number?): Line number
        {col}   (number?): Column number
        {winnr} ((number|string)?): Window to open the file in, current window
		if `nil`.

    Returns:
        (boolean) `true` if file was opened, `false` otherwise (see above).

    Returns:

        (number?) Line number if present
        (number?) Column number if present

LEGACY CONFIGURATION                                          *file_line_legacy*

It is not necessary to use the `setup` function, you can also call the old
configuration functions directly.

NOTE:
    The preferred way is to use the `setup` function (or `opts` field in lazy.nvim).
    These are not currently deprecated, but they may be in the future.

    {register()}	same as passing `register = true` to setup

    {onOpen(fn)}	same as passing `on_open = fn` to setup

    {enableGf(opts)}	same as passing `enable_gf = opts` to setup
